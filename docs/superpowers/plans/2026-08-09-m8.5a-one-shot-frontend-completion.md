# 9. State / Error / Concurrency Rules

## Authentication
Do not change:
- memory-only access token;
- HttpOnly refresh cookie;
- AuthProvider current-user ownership;
- single-flight refresh;
- one retry after successful refresh;
- safe `returnTo`;
- logout cache clearing.

## Money
- use integer minor units;
- use backend/system calculations;
- no floating-point financial calculations;
- MYR presentation via centralized formatter.

## Quantities
- preserve exact decimal strings;
- do not parse authoritative business quantities through JavaScript floating-point operations.

## ExpectedRevision / conflicts
Where backend exposes ExpectedRevision:
- send it;
- on 409 preserve user input;
- refetch authoritative state;
- explain that the record changed;
- require user review;
- do not silently retry a conflicting business mutation.

## Immutable/versioned records
Respect backend rules for:
- finalized Estimates;
- issued Quotations;
- Supplier Offer versions;
- Awards;
- receipts/other immutable business records.
